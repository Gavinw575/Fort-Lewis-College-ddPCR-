# Fort-Lewis-College-ddPCR-
This repository contains the design files and code for a low-cost, open-source optoelectrical system that counts fluorescent droplets in droplet-based microfluidics. A 473 nm laser excites droplets flowing through a quartz capillary. Fluorescence is collected by a microscope objective, filtered, and detected by a photomultiplier tube. The signal is conditioned by an analog front end (a four-stage RC filter, an LM324 gain stage, and two INA128P instrumentation amplifiers) and digitized by a USB-204 DAQ. Included are the KiCad schematic for the front-end circuit, the Qt/C++ live graphing and data-logging application, the MATLAB peak-counting script, the 3D-printed capillary holder, and a bill of materials. The system was verified by counting droplets containing pGreen E. coli against plate counts. It is meant to be reused, so anyone building a different optical system can swap in their own laser, filter, or detector.
